# Third-party components

Roundhouse is a modified fork of [KickTalk](https://github.com/KickTalkOrg/KickTalk),
originally designed and developed by Dark and ftk789. The upstream Git history and
GPL-3.0 license are retained. Baseline: a3570be165618f70449257bbb70df7cd16b66efe.

MPV is provided by the [shinchiro Windows builds](https://github.com/shinchiro/mpv-winbuild-cmake).
The exact build and archive hash are recorded in resources/mpv-manifest.json.
The downloaded archive's licenses are retained with the executable. MPV source:
https://github.com/mpv-player/mpv. Build scripts and corresponding dependency
versions are available in the pinned distributor release and its repository.

Other dependencies and their licenses are recorded in package-lock.json and their
installed package directories. KickTalk's icons, fonts, themes, and chat UI retain
their original attribution. Roundhouse is a personal project, not an official Kick product.
